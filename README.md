# Improved Fuzzy Soft Framework

This repository contains the implementation of the proposed framework described in the manuscript:

"Advancing Sustainable Agriculture through Multi-Parameter Fuzzy Soft Set–Based Plant Disease Classification"

## Features

- RGB Feature Extraction
- HSV Feature Extraction
- GLCM Feature Extraction
- Variance-Based Feature Weighting
- K-Means Prototype Generation
- Mahalanobis Similarity
- Fuzzy Soft Classification

## Dataset

PlantVillage Tomato Leaf Dataset

Dataset Link:

(https://www.kaggle.com/datasets/abdallahalidev/plantvillage-dataset)
